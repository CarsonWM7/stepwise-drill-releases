# Stepwise Drill — downloads

Drill writing software for marching band, drum corps and indoor ensembles.

**[Download the latest version](../../releases/latest)** — pick the file for your computer:

| Computer | File |
| --- | --- |
| Windows | `Stepwise Drill Setup x.y.z.exe` (installer) or `Stepwise Drill x.y.z.exe` (portable) |
| Mac | `Stepwise Drill-x.y.z-universal.dmg` |
| Linux | `.AppImage` or `.deb` |

The app tells you when a new version is out (it checks `latest-version.json` in this repository
when it starts). Nothing is installed automatically: download the new version here and install it
over the old one. Your shows are not affected.

This repository only holds the downloads; the app's source code is private.
